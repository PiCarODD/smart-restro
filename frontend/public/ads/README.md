# Advertisement Images

Place your 5 advertisement images in this folder with the following names:

- `ad-1.jpg` (or `.png`, `.webp`, etc.)
- `ad-2.jpg`
- `ad-3.jpg`
- `ad-4.jpg`
- `ad-5.jpg`

## Recommended Image Specifications

- **Format**: JPG, PNG, or WebP
- **Resolution**: 1920x1080 (Full HD) or higher
- **Aspect Ratio**: 16:9 (landscape)
- **File Size**: Keep under 2MB per image for optimal loading
- **Content**: Restaurant promotions, menu highlights, special offers, etc.

The images will automatically cycle through in a slideshow on the login page.

## Updating Images

After adding your images to this folder, they will be automatically displayed. No code changes needed!

If you want to change the image paths or add more images, edit `frontend/src/pages/auth/LoginPage.tsx` and update the `adImages` array.
